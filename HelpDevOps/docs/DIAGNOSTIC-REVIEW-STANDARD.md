# Diagnostic Review Standard

A reviewed journey must use primary sources, safe command wording, synthetic fixtures, explicit limitations, and compatibility metadata. Reviewers verify that read-only evidence comes first, unsupported certainty is absent, commands do not expose secrets, higher-risk actions include rollback, and completion requires verification.

Material corrections must update the resource version or review record, add a regression fixture, explain the correction in release evidence, and update the owner runbook when a new operational failure mode is discovered.

# Codex Workflow

## Roles
Govind owns vision, priority and final approval. ChatGPT owns research, design, architecture, specifications, review and quality gates. Codex owns implementation, automated tests, manual testing, bug fixing and implementation reporting.

## Flow
Research → Decisions → Approved EP Spec → Codex Implementation → Codex Testing/Fixes/Report → ChatGPT Audit → Govind Approval → One Commit + Full Snapshot.

Codex must not independently expand product scope or architecture.

# Network and Privacy Certification

HelpDevOps is expected to make only same-origin requests for its own HTML, scripts, styles, icons, and generated assets during normal use. Official documentation links are user-initiated navigation, not background analysis requests.

The full browser certification samples Universal Input, tools, diagnostics, interpreters, search, Workspace, and Incident Brief. Any unexpected background request to a third-party origin is a release blocker until understood.

Certification also verifies that raw evidence is not silently persisted, private-key material remains blocked, local storage is not described as encrypted or permanent, and correction reports attach no user evidence automatically.

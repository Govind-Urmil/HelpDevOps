# Release Workflow

One EP = one approved scope, one commit and one verification cycle. Update relevant metadata, tests and documentation. Every ZIP is a complete repository snapshot. Never claim tests passed unless actually run.

Artifact pattern: `HelpDevOps-vX.Y.Z-EP00X-FULL-SNAPSHOT.zip`.

Release gates: architecture, UX, mobile, SEO, accessibility, performance, regression, security/privacy, documentation and trust.

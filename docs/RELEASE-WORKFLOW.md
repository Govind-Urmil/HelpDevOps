# Release Workflow

One EP = one approved scope, one commit and one verification cycle. Update relevant metadata, tests and documentation. Every ZIP is a complete repository snapshot. Never claim tests passed unless actually run.

Artifact pattern: `HelpDevOps-vX.Y.Z-EP00X-FULL-SNAPSHOT.zip`.

The snapshot is generated by `npm run snapshot` and verified by `npm run snapshot:validate`. The validator rejects backslash paths and self-inclusion, extracts into a clean temporary directory, and verifies recovery-critical files. Dependencies, framework caches, build output, browser reports, temporary profiles, logs and local environment files are excluded according to `.gitignore`; source, tests, CI, documentation and lockfiles are required.

Public release is blocked while the centrally configured canonical URL uses the reserved `.example` domain.

Release gates: architecture, UX, mobile, SEO, accessibility, performance, regression, security/privacy, documentation and trust.

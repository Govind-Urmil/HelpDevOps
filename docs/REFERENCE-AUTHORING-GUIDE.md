# Reference Authoring Guide

1. Define the user question and evidence distinction.
2. Prefer authoritative primary sources.
3. Write concise explanations in original language.
4. State what the evidence does not prove.
5. Link only reviewed available destinations.
6. Record review dates and stability.
7. Run reference, discovery, link, metadata and build validation.
8. Update or deprecate rather than silently changing an ID meaning.

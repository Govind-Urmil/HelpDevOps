# EP-015 Release Notes

HelpDevOps now presents operational guidance with a calmer, more premium decision-first interface. Diagnostic commands are easier to scan and copy, the Errors index can be filtered locally, technology context is more consistent, Universal Input has clearer focus and drag feedback, and privacy assurances remain visible in the footer.

This release changes presentation and interaction foundations only. Analysis logic, reviewed guidance, local-only behavior, workspace compatibility, security controls, and deployment gates are unchanged.

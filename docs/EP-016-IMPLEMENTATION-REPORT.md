# EP-016 implementation report

EP-016 adds HOKS v1.0, a validated resource-driven operational knowledge catalog, deterministic matching, coverage derivation, a static knowledge directory split into five bounded technology routes with stable object anchors, concise progressive rendering, and owner maintenance guidance. The catalog contains 20 reviewed issue families each for Kubernetes, Docker, Linux/systemd, Git, and Terraform, backed by 300 generated positive, exclusion, and ambiguity fixtures. The bounded technology routes deliberately preserve Cloudflare's 100-rule header limit and existing page budgets while keeping the corpus off global page payloads.

Existing analyzers, evidence interpreters, diagnostic journeys, references, Workspace, Incident Brief, security headers, deployment gates, and privacy boundaries remain intact. Universal Input consults HOKS only after existing structured evidence and diagnostic routing and requires corroborating context. First recommendations are read-only and automated validation rejects dangerous defaults.

Deferred EP-015 polish is included through individual local technology SVG assets, a central registry and reusable renderer in selected cards, plus a 320px-only hero-decoration width constraint.

# ChatGPT Work Workflow

## Roles
Govind owns vision, priority and final approval. ChatGPT owns research, design, architecture, specifications and review. ChatGPT Work performs implementation, automated tests, manual testing, bug fixing and evidence reporting within approved specifications.

## Flow
Research → Decisions → Approved EP Spec → ChatGPT Work Implementation → Testing/Fixes/Report → ChatGPT Audit → Govind Approval → One Commit + Full Snapshot.

ChatGPT Work must not independently expand product scope or architecture.

# Accessibility Manual Checklist

Target: WCAG 2.2 AA readiness. Passing this checklist is evidence of review, not a legal or formal conformance claim.

- Page title, landmarks, headings, and reading order are meaningful.
- All primary actions work with keyboard only.
- Focus is visible and not obscured by sticky UI.
- Dialogs receive focus, trap it appropriately, close with Escape, and return focus.
- Dynamic analysis and copy/download status messages are announced without unexpected context changes.
- Errors identify the affected field and correction.
- High-risk, unknown, and verification states do not rely on color alone.
- Mobile targets are usable and essential content matches desktop.
- At 200% equivalent reflow there is no material horizontal scrolling for ordinary content.
- Reduced-motion preference removes non-essential animation.
- Command blocks, references, Incident Brief, Workspace, Emergency View, and search are sampled manually.

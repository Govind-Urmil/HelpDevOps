# Project Context

HelpDevOps is a long-term production asset and DevOps workspace. Priorities: Trust → Accuracy → Stability → UX → Performance → SEO → Monetization.

The product should reduce context switching through reliable tools, troubleshooting, references and a flagship browser-side DevOps Preflight capability.


EP-003 establishes the resource-driven Core Tool Platform. Routine wording, example, reference, alias, recommendation, and limitation updates should be resource changes where practical; new analysis behavior remains a code-and-test change.
